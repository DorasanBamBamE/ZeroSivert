# 2D ZeroSivert

제로시버트를 모작해서 제작하는 Unity 6 기반 2D 탑다운 생존·루팅 프로젝트입니다.

## Unity

- Version: 6000.2.8f1
- Main scenes: MainTitle, Hub, Forest

## Project layout

- Assets/ — scenes, scripts, sprites, prefabs, data
- Packages/ — Unity package manifest and lock file
- ProjectSettings/ — Unity project settings
- Docs/ — 작업 기록과 향후 로드맵

Unity에서 저장소 루트를 프로젝트로 열면 Library/가 자동 재생성됩니다.
