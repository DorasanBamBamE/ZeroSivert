## 적용 결과

- 제공된 `resource/Sound` 379개 파일을 분류하고 필요한 장면·상호작용 음원을 선별했다.
- `GameAudioLibrary`와 영속 `GameAudioManager`를 추가했다.
- MainTitle 메인 메뉴 음악, Hub 벙커 환경음, Forest 숲 환경음을 장면 전환에 맞춰 자동 교체한다.
- 모든 UI 버튼, 인벤토리 열기/닫기, 컨테이너 열기, 거래, 레벨업, 의료/음식/음료 사용, 실내/야외 발걸음에 효과음을 연결했다.
- 총기 12종에 개별 발사음과 재장전음, 공탄음을 연결했다.

## 탄약 세분화

기존 Small/Big/Shotgun 3분류를 아래 6개 구경으로 세분화했다. 직렬화 값 0~2는 기존 에셋 호환을 위해 유지했다.

- 5.45×39mm: AK74
- 7.62×39mm: AKM, SKS
- 12×70: MP153, TOZ
- 9×18mm: Makarov, APS, Vz61
- 7.62×25mm: PPSh-41
- 7.62×54R: Mosin-nagant, SV98, SVT-40

시작 장비 Makarov는 9×18mm FMJ 90발을 지급하며 실제 재장전 예비탄으로 소비한다.

## 아이템 확장

- SaveGameCatalog 총 아이템: 28종 → 70종
- 신규 42종 모두 고정 itemId와 아이콘을 보유한다.
- 추가 범주:
  - 일반/관통/확장형 탄약 12종
  - 멸균·군용 붕대, 야전 구급킷, 외상 치료 키트, 소독제, 방사능 억제제
  - 콩 통조림, 초콜릿, MRE, 에너지 드링크, 커피
  - 배터리, 못, 볼트와 너트, 공구, 전선, 모터, 테이프, 금속 파이프, 기계 오일
  - 비누, 담배, 성냥
  - 중형 배낭, 사냥꾼 방탄복

모든 신규 아이템은 원본 제공 스프라이트를 Point/16 PPU/무압축 Sprite 설정으로 복사해 사용한다.

## 직접 확인할 항목

1. 타이틀·벙커·숲의 음량 균형과 반복 지점이 자연스러운지
2. 이동 속도에 따른 발걸음 간격이 캐릭터 애니메이션과 맞는지
3. 12종 총기의 발사음이 체감상 총기 크기와 어울리는지
4. 상자 수 증가 후 Forest 프레임이 목표 60 FPS를 유지하는지
5. 신규 아이템 이름·가격·무게·아이콘 크기가 인벤토리에서 자연스러운지
6. 상점과 상자에서 특정 범주의 아이템이 지나치게 자주 또는 드물게 나오지 않는지
