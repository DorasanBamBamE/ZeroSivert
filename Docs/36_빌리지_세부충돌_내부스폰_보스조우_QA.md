## 빌리지 충돌 재작업

- 기존 담장 세그먼트 106개는 이미지 경계와 일치해 유지했다.
- 건물 여러 채를 묶던 `BuildingBlockers` 18개는 전부 제거했다.
- 원본 960×960 이미지 기준으로 건물 26개를 각각 분리했다.
- 차량·기계·배럴·적재물 20개를 별도 소품 충돌로 추가했다.
- 총 152개 콜라이더는 모두 `Obstacle`, 비 Trigger 상태다.

## 보스 조우

- 빌리지에 `Bandit Boss` 1명과 `Bandit Guard` 4명으로 구성된 전용 조우를 추가했다.
- 생성 확률은 75%다.
- 보스 지점 1개와 가드 지점 4개는 울타리 내부의 충돌 없는 공간에 고정했다.
- 일반 적 마커는 보스 조우 지점 반경 2.6유닛을 비운다.

10,000회 확률 검사 결과: `7,501 / 10,000 = 75.01%`.
