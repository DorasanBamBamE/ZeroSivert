# 42 — 인벤토리 퀵슬롯 · 허브 사격 차단 · 최종 QA

작성: 2026-08-24

## 1. 인벤토리 하단 퀵슬롯 표시

- 인벤토리를 열 때 `QuickBar`를 같은 Canvas의 마지막 형제로 올려 반투명 배경과 패널 위에 표시한다.
- 인벤토리를 닫으면 원래 형제 순서로 복원한다.
- Hub와 Forest 모두 `sibling 2 → 8(last)` 및 닫은 뒤 `2` 복원을 확인했다.
- 인벤토리 일시정지(`timeScale = 0`)와 퀵슬롯 등록 입력은 기존 동작을 유지한다.

## 2. Hub 사격 차단

- 플레이어 `Weapon.TryFire()` 진입부에서 활성 씬이 `Hub`이면 즉시 종료한다.
- Hub 검증: 탄약 `5 → 5`, 활성 총알 `0 → 0`.
- Forest 회귀 검증: 탄약 `5 → 4`, 활성 총알 `0 → 1`.
- 따라서 허브에서는 발사음·탄약 소비·총알 생성이 발생하지 않고 Forest 전투는 유지된다.
