# 39 — 빌리지 타일맵 정렬 · 남쪽 길 연결 QA

작성: 2026-08-24

## 원인

- `ZC_village_1/Grid`의 `fence`, `Road`, `Road2`가 `sortingOrder 5`여서 플레이어와 적보다 항상 앞에 그려졌다.
- 좀비와 늑대의 몸체는 order 0이라 order 1을 사용하는 플레이어·밴딧·구조물 전경과 정렬 기준이 달랐다.
- 마을 남쪽 출구 타일과 지면 도로 청크 사이에 약 9유닛의 빈 구간과 청크 경계 이음새가 있었다.

## 수정

| 대상 | 수정 전 | 수정 후 |
|---|---:|---:|
| 내부 바닥 `Tilemap` | order 1 | **order -7** |
| `Road`, `Road2` | order 5 | **order -7** |
| `fence` | order 5 · Chunk | **order 1 · Individual** |
| Zombie / Wolf 몸체 | order 0 | **order 1** |

- 바닥과 도로는 구조물 원본 아트(-8) 위, 캐릭터(1) 아래에서 그려진다.
- 울타리는 캐릭터와 같은 order 1에서 타일별 Y 정렬을 적용한다.
- 남쪽 직선 도로 타일을 로컬 Y `-22, -16, -10, -4, 2, 8`에 연속 배치해 지면 도로까지 연결했다.

적 몸체: 런타임 97개 sortingOrder 1 통일
