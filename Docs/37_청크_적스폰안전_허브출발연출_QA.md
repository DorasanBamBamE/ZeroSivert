## 1. 10×10 · 15×15 청크 적 스폰포인트 재배치

밴딧 청크 7종의 기존 적 스폰포인트를 모두 제거하고, 실제 `StructureCollision`에서 0.7유닛 이상 떨어진 안전 지점으로 다시 만들었다.

| 청크 | 적 스폰포인트 |
|---|---:|
| `10x10_4 · 10x10_6 · 10x10_7` | 각 14개 |
| `15x15_1 ~ 15x15_4` | 각 26개 |
| 합계 | 146개 |

- 청크 가장자리 0.9유닛을 비웠다.
- 구조물 콜라이더에서 최소 0.78유닛 이상 떨어뜨렸다.
- 루팅 스폰포인트와 1유닛 이내 겹침을 금지했다.
- 안전 후보 중 서로 가장 멀리 떨어지는 지점을 반복 선택해 청크 전역에 분산했다.

검증:

```yaml
적 스폰포인트        : 146
콜라이더 0.7 이내    : 0
루팅 포인트 1.0 이내 : 0
청크 경계 밖         : 0
```

## 2. 허브 → Forest 출발 연출

`ZoneEntryPoint.Depart()`가 즉시 씬을 바꾸던 흐름을 출발 코루틴으로 변경했다.

1. 중복 출발 입력을 잠근다.
2. 원작 `s_loading_forest_0` 이미지를 페이드 인한다.
3. `FOREST / RAID DEPLOYMENT` 제목과 원작 PDA 로딩 바 21프레임을 1.4초 동안 순서대로 표시한다.
4. 기존 RunData 저장·레이드 시작·디스크 저장을 실행한다.
5. 기존 `SceneLoader` 페이드로 Forest를 비동기 로드한다.

전용 이미지:

- `Assets/Resources/UI/Travel/s_travel_forest.png`
- `Assets/Resources/UI/Travel/LoadingBar/s_hud_loading_pda_0.png ~ _20.png`

연출 확인 캡처:

- `Assets/Screenshots/hub_forest_departure_original_assets.png`
