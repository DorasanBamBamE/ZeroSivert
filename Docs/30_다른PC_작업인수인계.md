# 30 — 다른 PC 작업 인수인계

작성: 2026-08-23  
목적: 전체 Unity 프로젝트는 사용자가 직접 ZIP으로 옮기고, GitHub에는 작업 진척도와 QA 기록만 보관한다.

## 기준 원본

- 실제 작업 기준은 사용자가 옮긴 `2D ZeroSivert` ZIP 압축본이다.
- GitHub의 코드·씬·에셋은 현재 ZIP과 동일하다고 간주하면 안 된다.
- 다른 PC에서 작업을 시작할 때 GitHub 코드로 ZIP 프로젝트를 덮어쓰거나 `git reset`하지 않는다.
- GitHub의 `Docs`는 작업 이력과 확인 목록을 읽는 용도로 사용한다.

## 다른 PC에서 시작하는 순서

1. ZIP을 짧은 로컬 경로에 해제한다. OneDrive 동기화 폴더보다 일반 로컬 폴더를 권장한다.
2. Unity Hub에서 압축 해제한 프로젝트 폴더를 연다.
3. Unity `6000.2.8f1`을 사용한다.
4. 최초 임포트와 스크립트 컴파일이 끝날 때까지 기다린다.
5. Console 오류를 확인하고 Unity MCP 연결 인스턴스의 프로젝트 경로가 ZIP 해제 위치와 일치하는지 확인한다.
6. `Docs/19_향후_작업목록_로드맵.md`, `Docs/29_타이틀_레이드왕복_저장통합QA.md`, 이 문서를 먼저 읽는다.
7. MainTitle에서 Play, Config, LOAD GAME/NEW GAME 전환을 확인한 뒤 Hub를 연다.

## 마지막 확인 상태

- MainTitle의 Play / Exit / Config와 새 게임·불러오기 선택창이 동작한다.
- 새 게임 초기 장비와 Hub → Forest → 정상 탈출 → Hub 복귀 흐름을 확인했다.
- 역무원 말풍선, 대화, 출발 버튼이 동작한다.
- 생존 결과 화면이 LOAD GAME 때 반복되던 문제를 수정했다.
- Windows Development 빌드 `Builds/Windows_E2EQA/ZeroSivert.exe`가 오류 0건으로 성공했다.
- 마지막 런타임 콘솔 오류/경고는 0/0이었다.
- Git 커밋 및 GitHub 업로드 전 상태이므로 ZIP 내부 파일이 가장 최신이다.

2026-08-24 후속 QA에서 위 흐름을 실제 입력으로 다시 통과했다. Hub NPC·충돌과 총기 12종을 전수 검사했고, 밴딧 탄약 드롭 구경 불일치와 무기 아이콘 품질을 수정했으며 재질별 탄착 VFX를 추가했다. 상세는 `31_다른PC_통합QA_무기_루팅_VFX.md`를 참조한다.

2026-08-24 Forest 후속 QA에서 구조물 기대 배치 수를 14.10에서 8.25로 낮추고 구조물별 적·전리품 수를 제한했다. 구조물·전리품 상자 실체 충돌체를 시각 범위에 맞춰 축소하고, 총알의 상호작용 Trigger 오인 차단과 퀵슬롯 대형 아이콘 넘침을 수정했다. 상세는 `32_숲_스폰밀도_충돌_퀵슬롯_QA.md`를 참조한다.

2026-08-24 추가 QA에서 Forest 청크 프리팹 13종의 충돌체를 전수 대조했다. 이미지에 없던 충돌체 9개를 제거하고 건물·울타리·소품 충돌체를 실제 접지부에 맞춰 보정했으며, 런타임 적·상자 충돌 겹침과 Console 오류/경고가 모두 0임을 확인했다. 상세는 `33_청크_콜라이더_전수보정_QA.md`를 참조한다.

2026-08-24 사용자 이미지 기준 재작업에서 청크 구조물 충돌을 전체 오브젝트 실루엣으로 확장하고 Obstacle 레이어를 통일했다. 루팅 마커는 밴딧 청크 59곳과 빌리지 12곳의 실제 이미지 상자 좌표로 교체했다. Forest 구조물 기대 수는 11.75개, 야생 무리는 7~9그룹이며 밴딧 정찰대 4~5명을 최소 1그룹 보장한다. 실행 검증은 구조물 11개, 무리 9그룹 38마리, 구조물 내부 적 겹침 0, Console 0/0이었다. 상세는 `34_청크_이미지충돌_루팅좌표_적무리증대_QA.md`를 참조한다.

2026-08-24 후속 보정에서 밴딧 청크 `StructureCollision`을 다시 전면 교체했다. 큰 결합 사각형을 제거하고 원본 PNG의 개별 구조물 경계에 맞춘 96개 자식 콜라이더로 분리했으며, 실행 검증에서 구조물 내부 적 겹침과 Console 오류/경고는 0이었다. 상세는 `35_StructureCollision_이미지단위_재작업_QA.md`를 참조한다.

2026-08-24 빌리지 후속 보정에서 건물 26개와 차량·기계·배럴·적재물 20개를 이미지 단위 충돌로 분리했다. 루팅과 적 마커는 모두 울타리 내부로 옮겼고 일반 적은 18~24명으로 상향했다. Bandit Boss 1명과 Guard 4명의 75% 확률 조우를 추가했으며 실제 실행에서 보스 조우 5명, 내부 충돌 겹침 0, Console 0/0을 확인했다. 상세는 `36_빌리지_세부충돌_내부스폰_보스조우_QA.md`를 참조한다.

2026-08-24 청크 적 스폰 후속 보정에서 밴딧 청크 7종의 적 스폰포인트 146개를 실제 콜라이더 기준으로 전면 재배치했다. Hub에서 Forest로 출발할 때 전용 이미지·지역명·진행 바를 표시하는 연출도 추가했다. 실제 실행에서 구조물 13곳·적 94명 중 장애물 겹침 0, 출발 전환 정상, Console 0/0을 확인했다. 상세는 `37_청크_적스폰안전_허브출발연출_QA.md`를 참조한다.

2026-08-24 PDA 후속 작업에서 `Perk`, `Base`, `Faction` 세 탭을 정보 확인용으로 간략 구현했다. Hub와 Forest 모두 패널 5개·버튼 5개 연결, 누락 참조 0, 실행 표시 정상, Console 0/0을 확인했다. 상세는 `38_PDA_미구현3탭_간략구현_QA.md`를 참조한다.

2026-08-24 빌리지 후속 보정에서 타일맵 바닥·도로의 과도한 렌더 순서를 낮추고 울타리를 Individual Y 정렬로 변경했다. 좀비·늑대 몸체 정렬을 다른 캐릭터와 통일했으며 남쪽 출구와 지면 도로 사이의 단절을 제거했다. 실행 화면과 Console 0/0을 확인했다. 상세는 `39_빌리지_타일맵_정렬_남쪽길_연결_QA.md`를 참조한다.
