# 17 — 빌리지 외곽 숲 타일 · 북쪽 길 보정

작성: 2026-08-21

---

## 1. 회색 외곽 타일의 원인

빌리지 주변 8×8 링은 레이아웃 문자 `A~P`로 구성돼 있었다. 그중 `E~P`의 Ground Palette 프리팹이 null이라 플레이 모드에서 지면이 생성되지 않았고, 카메라 배경색이 회색 사각형으로 노출됐다.

또한 `PropScatter.groundSymbols`가 `.A`만 허용해 나머지 외곽 문자에는 나무·풀·덤불이 배치되지 않았다.

---

## 2. 외곽을 일반 숲으로 변경

북쪽 진입로 `C`를 제외한 빌리지 외곽 문자 15개를 모두 일반 숲 프리팹으로 교체했다.

```yaml
A, B, D~P : GC_grass
C          : GC_vr_12_18  # 북쪽 길
null 항목   : 0
```

옛 `마을 외곽_*` 오버레이는 재생성 후 0개가 됐다. 외곽 링은 일반 숲 청크와 같은 `zc_forest_grass_2x`를 사용한다.

---

## 3. 프롭 배치 범위

`PropScatter.groundSymbols`를 다음과 같이 바꿨다.

```text
.ABDEFGHIJKLMNOP
```

북쪽 길 `C`에는 프롭을 깔지 않고, 나머지 외곽 숲에는 본 숲과 같은 밀도·간격 규칙을 적용한다.

빌리지의 프롭 제외 Bounds를 계산할 때 `RoadConnector_*`를 제외했다. 북쪽 길이 길다는 이유로 주변 숲 한 줄 전체가 구조물 영역으로 묶이지 않는다.

플레이 모드 외곽 링 결과:

```yaml
나무 : 129
풀   : 539
덤불 : 32
```

랜덤 시드에 따라 나무 수와 위치는 실행마다 조금 달라진다.

---

## 4. 북쪽 길 정렬

북쪽 외곽 한 칸만 `GC_vr_12_18` 도로로 유지했다. 빌리지의 `RoadConnector_NorthWest` 3개는 X 좌표를 조정했다.

```yaml
이전 X : 3.5
이후 X : 2.0
Y      : 40 / 50 / 60
```

외부 `road_12_10`의 세로 도로 중심과 빌리지 내부 연결로 중심이 이어지며, 나머지 외곽 도로 링은 제거됐다.

---

## 5. 생성 순서 보정

씬에 저장된 옛 프롭 콜라이더가 새 구조물 스폰을 막지 않게 실행 순서를 고정했다.

```yaml
ZoneGenerator : DefaultExecutionOrder(-100)
PropScatter   : DefaultExecutionOrder(100)
```

`PropScatter.Awake()`에서 편집용 `Props` 루트를 즉시 비활성화하고, 존 생성이 끝난 뒤 새 프롭을 산포한다.
