# 35 — StructureCollision 이미지 단위 재작업 QA

작성: 2026-08-24

## 원인

34번 작업의 밴딧 청크 `StructureCollision`은 여러 구조물을 하나의 큰 사각형으로 묶었다. 그 결과 구조물 사이의 빈 잔디까지 막히고 작은 소품 일부는 충돌에서 빠졌다.

## 재작업

- 밴딧 청크 원본 PNG 7장을 16px 격자와 픽셀 경계로 다시 대조했다.
- 기존 `StructureCollision` 56개를 전부 제거했다.
- 건물·울타리 구간·탑·작업대·기계·차량·상자 더미를 개별 시각물 단위로 분리했다.
- 각 콜라이더를 `StructureCollision/Collider_XX` 자식으로 분리해 이후 수동 보정이 가능하게 했다.
- 콜라이더는 모두 비 Trigger이며 `Obstacle` 레이어다.

| 청크 | 재작성 콜라이더 |
|---|---:|
| `10x10_4` | 9 |
| `10x10_6` | 6 |
| `10x10_7` | 8 |
| `15x15_1` | 17 |
| `15x15_2` | 21 |
| `15x15_3` | 19 |
| `15x15_4` | 16 |
| 합계 | 96 |

총 충돌 면적은 492.57 유닛²이며 모든 사각형이 청크 이미지 내부에 있다.
