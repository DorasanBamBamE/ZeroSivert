작성: 2026-08-21

## 1. 빌리지 외곽에 구조물이 중복돼 보이던 원인

Forest 씬에는 에디터 확인용으로 생성된 `Ground`와 `Structures` 루트가 저장돼 있다. 플레이가 시작되면 `ZoneGenerator.Start()`가 맵을 다시 만들지만, 기존 구현은 옛 루트를 `Destroy()`만 호출했다.

`Destroy()`는 프레임 끝에 실행되므로 한 프레임 동안 다음 두 세트가 겹쳤다.

```text
씬에 저장된 이전 Structures
+ Start()가 새로 만든 Structures
```

이 때문에 빌리지 외곽 건물이 한 번 더 생성된 것처럼 보이고, 이전 구조물의 콜라이더가 새 스폰 지점을 막는 현상도 함께 발생했다.

### 수정

`ZoneGenerator.DestroyRoot()`가 이전 생성 루트를 먼저 즉시 비활성화한 뒤 제거하도록 변경했다.

```csharp
target.gameObject.SetActive(false);
Destroy(target.gameObject);
```

렌더러와 콜라이더가 같은 프레임에 즉시 꺼지므로 새 구조물과 겹치지 않는다.

## 2. 빌리지 인접 구조물 슬롯 재배치

마을 경계에서 약 25유닛밖에 떨어지지 않았던 선택형 오두막 3개를 외곽으로 옮겼다.

| 슬롯 | 이전 | 이후 |
| --- | ---: | ---: |
| 북서 오두막 | `(70, 205)` | `(60, 230)` |
| 동중 오두막 | `(205, 120)` | `(265, 145)` |
| 남중 오두막 | `(95, 85)` | `(150, 55)` |

빌리지 60×60 영역에 35유닛의 여유 영역을 더한 뒤 다른 구조물 사각형과 비교했다. 해당 여유 영역에 들어오는 외부 구조물 슬롯은 **0개**다.

## 3. 밴딧 존 프리팹 구조물 콜라이더

기존 밴딧 프리팹 7종에는 배경 스프라이트만 있고 구조물 콜라이더가 없었다. 각 이미지의 건물·창고·울타리·차량·작업대 형상에 맞춰 `StructureCollision`을 추가했다.

| 프리팹 | 충돌 Box 형상 |
| --- | ---: |
| `bandit_10x10_4` | 6 |
| `bandit_10x10_6` | 5 |
| `bandit_10x10_7` | 5 |
| `bandit_15x15_1` | 11 |
| `bandit_15x15_2` | 9 |
| `bandit_15x15_3` | 13 |
| `bandit_15x15_4` | 8 |

- Static `Rigidbody2D`
- `CompositeCollider2D` Polygons
- BoxCollider2D `Merge`
- Layer / Tag = `Obstacle`

빌리지는 기존 `Walls` 106개와 `BuildingBlockers` 18개, 합계 **124개 Box 형상**을 그대로 사용한다.

## 4. 스폰포인트 전면 재작성

옛 스폰포인트는 구조물 모양과 무관한 격자라 건물·울타리·차량 안에도 적과 상자가 생성될 수 있었다. 모든 마커를 제거하고 콜라이더로부터 안전거리를 확보한 위치만 다시 만들었다.

| 구조물 크기 | 적 마커 | 루팅 마커 |
| --- | ---: | ---: |
| 10×10 | 12 | 10 |
| 15×15 | 24 | 16 |
| 빌리지 | 48 | 28 |

`StructureSpawner`에도 런타임 안전 검사를 추가했다.

1. 프리팹 내부 BoxCollider2D와의 거리 검사
2. 외부 `Obstacle`과의 원형 중첩 검사
3. 부적합한 마커는 건너뛰고 다음 안전 마커를 사용
4. 자기 구조물 아래에 생성된 루팅 상자는 외부 장애물 검사에서 제외

따라서 이후 프리팹을 수정하더라도 잘못 남은 마커에서 적이나 상자가 바로 생성되지 않는다.

## 5. 길 연결 재점검

빌리지 중앙 교차로, 내부 진입로, 북서 연결 조각을 게임 카메라 기준으로 다시 확인했다.

- 지면과 빌리지 도로 사이 절단선 없음
- 중앙 가로·세로 도로 연속
- `RoadConnector_NorthWest` 3개 유지
- 외부 오두막 재배치 후 빌리지 길 침범 없음
