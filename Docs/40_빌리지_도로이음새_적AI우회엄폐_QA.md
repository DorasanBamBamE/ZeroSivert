## 2. 공통 장애물 우회

`EnemyControllerBase`에 모든 적이 공유하는 2D 장애물 회피 이동을 추가했다.

- 전방 `CircleCast`로 `Obstacle`을 감지한다.
- 좌우 후보 각도 `32 / 58 / 88 / 118도`를 검사해 통과 가능한 방향을 선택한다.
- 재탐색 주기는 `0.12초`이며 짧은 시간 같은 우회 방향을 유지해 좌우 진동을 줄인다.
- 순찰·수색·근접 추격·원거리 접근/후퇴/횡이동이 같은 이동 경로를 사용한다.

근접 적 벽 우회 통제 시험:

```yaml
시작                 : (125.0, 5.0)
목표                 : (133.0, 5.0)
벽                   : 중심 (129.0, 5.0), 크기 (2.0, 4.0)
종료                 : (132.30, 4.38)
회피 동작 프레임       : 105
경로 재탐색            : 25회
최대 측면 우회 거리     : 2.50
결과                 : 벽 관통 없이 목표 측으로 우회 성공
```

## 3. 밴딧 엄폐 행동

`RangedEnemyController`에 시야 노출과 재장전 상황을 기준으로 엄폐 지점을 찾는 행동을 추가했다.

- 연속 노출 `2.4초` 또는 재장전 중이면 반경 `6유닛`의 장애물을 탐색한다.
- 장애물의 플레이어 반대편 후보를 만들고, 점유 여부와 실제 시야 차단 여부를 검사한다.
- 엄폐 이동 중 Alert 상태를 유지하고, 도착 후 최소 `1.1초` 또는 재장전 종료까지 엄폐한다.
- 적절한 엄폐물이 없으면 기존 교전 이동으로 복귀한다.

원거리 적 엄폐 통제 시험:

```yaml
플레이어             : (128.5, 15.0)
밴딧 시작            : (125.0, 15.0)
엄폐물               : 중심 (126.0, 18.0), 크기 (2.0, 2.0)
선택 엄폐점           : (124.48, 19.62)
밴딧 종료            : (124.24, 18.42)
엄폐 결정            : 1회
엄폐 이동 프레임       : 74
플레이어 시야 차단      : 성공
```
