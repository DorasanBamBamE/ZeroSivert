## 1. 북쪽 길 재점검

상단 도로 청크와 빌리지 연결로를 화면 캡처와 원본 스프라이트 픽셀 기준으로 다시 비교했다.

연결 조각을 오른쪽으로 옮기면 빌리지 원본에 이미 그려진 길과 겹쳐 갈색 띠가 하나 더 생겼다. 따라서 연결 조각은 원래 정렬값으로 복구하고, 상단 전용 청크는 지면 셀 기준점과 아트를 분리해 재생성 때 위치가 틀어지지 않도록 했다.

```yaml
북쪽 지면 셀 루트 : (120, 180)
GC_vr_12_18/Art   : local (0, 0)
RoadConnector X   : 2.0
RoadConnector Y   : 40 / 50 / 60
```

`RoadConnector_NorthWest`는 씬에만 남는 임시 오브젝트가 아니라 `ZC_village_1` 프리팹 자체에 포함시켰다. `ZoneGenerator.Generate()`가 구조물을 다시 만들어도 북쪽 연결로가 유지된다.

검증 이미지: `Assets/Screenshots/forest_north_road_final_aligned.png`

## 2. 야생 무리 스폰 테이블

기존 `EnemySpawner_Wild`의 개별 10마리 무작위 배치를 그룹 테이블 방식으로 교체했다.

데이터 에셋:

```text
Assets/4.Data/Spawn/WildGroups_Forest.asset
```

| 그룹 | 가중치 | 무리당 마릿수 | 최초 산개 반경 | 배회 반경 |
|---|---:|---:|---:|---:|
| 좀비 | 0.58 | 3~5 | 3.5 | 7 |
| 늑대 | 0.42 | 3~5 | 4.5 | 9 |

한 무리는 같은 테이블 항목의 프리팹만 사용한다. 즉 좀비와 늑대가 한 무리에 섞이지 않는다.

---

## 3. 배치 규칙

```yaml
맵 전체 무리 수       : 4~5
밤의 무리 수          : 5 (설정 상한 유지)
무리 중심 최소 간격   : 35
구조물 추가 여백       : 8
무리원 최소 간격      : 1.25
플레이어 안전 반경     : 25
장애물 검사 반경       : 0.6
```

무리 중심과 각 무리원 위치는 모두 다음 조건을 통과해야 한다.

1. 유효한 숲 지면 안
2. 플레이어 안전 반경 밖
3. 구조물 렌더러 Bounds + 8유닛 밖
4. 나무·벽 등 `obstacleMask` 콜라이더와 겹치지 않음
5. 다른 무리 또는 같은 무리원과 설정 간격 이상

`EnemySpawner`의 실행 순서를 `DefaultExecutionOrder(200)`으로 지정했다. 존 구조물(-100)과 프롭(100)이 생성된 뒤 야생 무리가 배치되므로 나무 밑동이나 구조물 안에 생성되지 않는다.

---

## 4. 그룹 배회

`EnemyControllerBase.ConfigureGroupPatrol()`을 추가했다.

각 무리원은 자신의 최초 위치를 따로 기준으로 삼지 않고, 공통 무리 중심을 `homePosition`으로 사용한다. 좀비는 중심 반경 7, 늑대는 반경 9 안에서 흩어져 배회한다.

적이 경계·수색 상태로 전환되는 전투 로직은 그대로 유지한다.
