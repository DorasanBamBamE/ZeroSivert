# 21 — 숲 건물 정렬 · 랜덤 시드 · 전투 검증

작성: 2026-08-22  
상태: 랜덤 시드 및 안전 스폰 보완 완료 — 건물 깊이 정렬·장시간 전투 관찰 남음

## 1. 범위

- 19번 로드맵의 2순위 작업을 이어서 진행한다.
- Hub → Forest 실제 출발 경로로 런타임을 시작한다.
- 반복 검사는 Play Mode 안에서만 시드를 바꾸며, 종료 후 런타임 변경을 폐기한다.
- 커밋과 GitHub 업로드는 사용자 승인 전까지 하지 않는다.

## 2. 수정 전 20개 시드 검사

`ZoneGenerator.seed`를 1000~1019로 바꾸어 구조물과 `EnemySpawner`를 매회 다시 생성했다.

```yaml
구조물 수 평균      : 14.15
야생 무리 수        : 4~5
무리당 개체 수      : 3~5
야생 적 평균        : 17.75
무리 중심 최단 거리 : 38.07
맵 밖 생성          : 0
Obstacle 위 생성    : 0
구조물 여백 침범    : 0
플레이어 15유닛 침범 : 0
탈출 지점 15유닛 침범: 2
탈출 지점 최단 거리 : 13.34
```

구조물 내부 적·상자는 transform 좌표가 아니라 실제 비 Trigger Collider2D끼리 `Collider2D.Distance`로 검사했다. 최종 활성 시드에서 구조물 벽/가구와 실제 겹침은 0건이었다.

## 3. 원인

`EnemySpawner`는 다음 항목을 검사하고 있었다.

- 맵 내부
- 플레이어 `safeRadius`
- `Obstacle` 레이어
- 구조물 렌더러 Bounds + `structurePadding`
- 무리 중심/구성원 간격

하지만 `ExtractionZone`은 전혀 조회하지 않아 탈출 지점 근처에도 야생 무리가 배치될 수 있었다. 프롭은 이미 `PropScatter.clearSymbols = { 'S', 'X' }`, `clearRadius = 9`로 진입/탈출 셀을 보호하고 있었다.

## 4. 구현

`Assets/3.Script/Enemy/EnemySpawner.cs`에 다음을 추가했다.

- `extractionSafeRadius = 15f`
- 활성 `ExtractionZone[]` 자동 탐색
- 플레이어와 모든 활성 탈출 지점을 함께 검사하는 `IsNearProtectedPoint`
- 그룹 중심, 그룹 구성원, 구형 개별 스폰 경로 모두 같은 보호 판정 사용

기존 `safeRadius`, 구조물 여백, 장애물 마스크, 무리 간격 규칙은 변경하지 않았다.

## 5. 수정 후 재검사

새 시드 2000~2019로 20회 다시 생성했다.

```yaml
총 야생 적          : 354
야생 무리 수        : 4~5
무리당 개체 수      : 3~5
탈출 보호 반경      : 15
탈출 반경 침범      : 0
탈출 지점 최단 거리 : 26.04
콘솔 오류/경고      : 0/0
```

`EnemySpawner.cs` 표준 스크립트 검사도 오류 0, 경고 0으로 통과했다.

## 6. Forest 씬·프리팹 구조 확인

- Forest 씬 Validator: 누락 스크립트 0, 깨진 Prefab 0, 전체 이슈 0
- Zone 크기: 30 × 30셀, 셀 크기 10유닛
- 현재 구조물 후보: Village 1종, 10×10 밴딧 3종, 15×15 밴딧 4종
- 모든 구조물 원본 SpriteRenderer는 `sortingOrder = -8`
- 모든 구조물 스프라이트는 Bottom-Left pivot
- 구조물 이미지는 투명 오버레이가 아니라 전체가 불투명한 완성 청크

따라서 단순히 구조물 전체를 플레이어와 같은 정렬 순서로 바꾸면 10×10~60×60 불투명 청크가 플레이어를 통째로 덮는다. 건물 깊이 정렬은 바닥과 전경/지붕을 분리한 별도 아트 또는 영역별 전경 마스크가 필요하므로, 자동 일괄 변경은 하지 않았다.

## 7. 남은 작업

- 건물 바닥과 전경/지붕을 분리할 안전한 마스크 기준 확정
- 마을 60×60 청크부터 건물 단위 전경 레이어 시험 적용
- 플레이어가 건물 남쪽에서는 전면, 북쪽에서는 후면으로 보이는지 확인
- 밴딧·늑대·좀비가 벽과 울타리를 통과하지 않는지 10분 이상 관찰
- 총알과 시야 Raycast의 `Obstacle` 차단 확인
- 여러 무리가 구조물 모서리에 장시간 끼지 않는지 확인
- 북쪽 길을 해상도별로 직접 캡처해 색·알파·프롭 침범 확인

## 8. 사용자가 직접 확인할 항목

- Forest 진입 직후 탈출 지점 주변에 적이 붙어 생성되지 않는지
- 야생 무리가 서로 한 덩어리처럼 겹치지 않고 4~5곳에 분산되는지
- 마을과 캠프의 건물 앞/뒤에서 플레이어가 현재 항상 위에 보이는 문제의 체감 정도
- 벽 뒤 밴딧이 플레이어를 감지하거나 사격하는지
- 적이 나무·담장·건물 모서리에 계속 끼는지
