- [ ] NPC와 플레이어가 카운터·벽을 통과하지 않는지 확인

## 4. 2순위 — 숲 맵 잔여 문제 마감

### 4-1. 건물과 플레이어 깊이 정렬

13번에서 남은 핵심 시각 문제다. 현재 구조물 아트가 고정 `sortingOrder -8`이라 플레이어가 건물 뒤로 이동해도 항상 건물 앞에 보인다.

- [ ] 빌리지/밴딧 건물을 바닥·벽 하단·벽 상단/지붕 레이어로 분리
- [ ] 플레이어와 적이 건물 뒤에 있을 때 상단/지붕에 가려지도록 구현
- [ ] 건물 앞에서는 플레이어가 정상적으로 전면에 보이게 설정
- [ ] 나무·적·플레이어의 Custom Axis Y 정렬과 충돌하지 않는지 확인
- [ ] 필요하면 건물 진입 불가 구역은 정렬 대신 완전 차단으로 단순화

완료 기준:

```yaml
건물 앞/뒤 반전 오류 : 0
플레이어 지면 밑 묻힘 : 0
나무 Y 정렬 오류      : 0
```

### 4-2. 랜덤 시드 반복 검증

한 번의 정상 실행만으로는 구조물·야생 무리·전리품의 모든 조합을 확인할 수 없다.

- [ ] 서로 다른 시드 최소 20회 생성
- [ ] 매 실행 구조물 수, 야생 무리 수, 적/상자 수 기록
- [ ] 구조물 내부 적·상자 0건 확인
- [ ] 맵 밖·나무 밑동·벽 위 야생 적 0건 확인
- [ ] 진입/탈출 지점 반경에 적과 프롭이 생성되지 않는지 확인
- [ ] 늑대/좀비 무리가 3~5마리 범위를 벗어나지 않는지 확인
- [ ] 무리 중심이 최소 35유닛 이상 떨어지는지 확인

### 4-3. 적 이동·사격·시야 차단 장시간 테스트

- [ ] 밴딧이 울타리·벽·건물을 통과하지 않는지 10분 이상 관찰
- [ ] 총알이 `Obstacle`을 통과하지 않는지 확인
- [ ] 시야 Raycast가 벽 뒤 플레이어를 감지하지 않는지 확인
- [ ] 늑대·좀비 무리가 구조물 모서리에 영구적으로 끼지 않는지 확인
- [ ] 추적 후 경계가 해제되면 각자 무리 중심으로 복귀하는지 확인
- [ ] 여러 무리가 가까워졌을 때 과도하게 한 점에 겹치지 않는지 확인

### 4-4. 북쪽 길과 빌리지 최종 시각 검사

- [ ] 게임 해상도별 북쪽 도로 연결 캡처
- [ ] 길 경계의 색·알파·반복 무늬 확인
- [ ] 길 위에 나무·덤불이 침범하지 않는지 확인
- [ ] 빌리지 외곽에 회색/빈 타일이나 별도 건물이 다시 생성되지 않는지 확인

## 5. 3순위 — 성능 최적화

현재 프롭 밀도는 원작 재현을 위해 크게 올린 상태다. 시각 품질을 유지하면서 실제 빌드 성능을 확인해야 한다.

### 5-1. 프로파일링

- [ ] Unity Profiler로 Hub/Forest의 CPU·GPU·메모리 기록
- [ ] 에디터가 아닌 Windows Development Build에서도 측정
- [ ] 숲 중앙·빌리지·구조물 밀집 지역·전투 중 프레임 비교
- [ ] `SpriteRenderer`, `Collider2D`, 물리 쿼리, 적 AI 비용 분리 측정
- [ ] Props/Ground/Box Atlas 배칭이 유지되는지 확인

권장 목표:

```yaml
해상도          : 1920×1080
목표 FPS        : 60
프레임 타임      : 평균 16.7ms 이하
콘솔 GC 경고     : 0
플레이 중 메모리 증가 : 지속 누적 없음
```

### 5-2. 필요할 때 적용할 최적화 순서

1. 화면 밖 풀 렌더러 컬링 범위 조정
2. 풀 밀도만 단계적으로 감소
3. 프롭 블록 단위 활성/비활성 범위 조정
4. 나무 콜라이더의 물리 레이어와 쿼리 범위 축소
5. 적 AI의 탐색·시야 검사 주기 분산
6. 반복 생성 오브젝트 풀링 검토

큰 나무와 작은 나무 밀도는 길 찾기와 가시성에 직접 영향을 주므로 풀보다 나중에 낮춘다.
