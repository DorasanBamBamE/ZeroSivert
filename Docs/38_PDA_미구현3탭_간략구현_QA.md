# 38 — PDA 미구현 3탭 간략 구현 QA

작성: 2026-08-24

## 작업 범위

`Perk`, `Base`, `Faction`을 기존 PDA 내부 탭으로 연결했다. 별도 성장 트리·기지 업그레이드·세력 보상 시스템은 만들지 않고 현재 저장 및 런타임 데이터를 읽는 요약 화면으로 제한했다.

| 탭 | 표시 내용 |
|---|---|
| `Perk` | 헌터 레벨·경험치, 무기 숙련 합계, 이동·중량·루팅 속도 보정 |
| `Base` | 현재 위치, 루블, 보유 아이템 수, 가방 무게, 이용 가능 시설 |
| `Faction` | 그린 아미·크림슨 평판과 등급, 세력별 진행 의뢰 수 |

## 적용 내용

- `PDAFeaturePanel`을 추가해 활성 탭에서만 0.25초 간격으로 실제 데이터를 갱신한다.
- `PDAController` 내부 배열을 2개에서 5개로 확장했다.
- 탭 순서는 `Stats / Perk / Gun / Base / Faction`이다.
- Hub와 Forest에 동일한 세 패널과 버튼 연결을 적용했다.
- PDA 화면 크기에 맞춰 제목·본문·안내 문구의 글꼴과 배치를 조정했다.

## 검증

```yaml
Hub   : 패널 5 · 버튼 5 · 누락 참조 0 · 기능 패널 3
Forest: 패널 5 · 버튼 5 · 누락 참조 0 · 기능 패널 3
실행 표시: Perk / Base / Faction 정상
Console: 에러 0 · 경고 0
```

## 의도적으로 제외한 범위

- 퍽 포인트 배분과 스킬 트리
- 기지 건설·업그레이드·시간 진행
- 세력 가입·보상 트리·상점 해금

현재 단계에서는 정보 확인용 간략 탭으로 완료하며, 위 기능은 별도 콘텐츠 확장 작업으로 분리한다.
