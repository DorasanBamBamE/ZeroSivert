# 27. 타이틀 설정 · 탄종 관통 · 재질 음향 통합

작업일: 2026-08-22

## 적용 결과

### 타이틀 설정

- 기존 타이틀의 3개 버튼을 게임 시작, 새 게임, 설정, 종료의 4개 버튼으로 정리했다.
- 설정 화면에 전체 음량, 음악/환경음, 효과음 슬라이더를 추가했다.
- 전체 화면 전환과 1280×720, 1600×900, 1920×1080, 2560×1440 해상도 선택을 추가했다.
- 적용값은 PlayerPrefs에 저장되어 다음 실행 때 복원된다.
- 취소 또는 ESC는 미리 듣기 음량을 되돌리고, 설정 중에는 뒤쪽 메뉴 버튼을 숨긴다.

### 탄종별 전투

- ItemData에 피해 배율, 방어구 관통력, 출혈 배율, 발사체 수, 산탄 퍼짐 프로필을 추가했다.
- 총 15종 탄약에 개별 프로필을 적용했다.
- 재장전 시 실제로 소비한 탄종을 탄창이 기억하며, 서로 다른 탄종을 한 번의 재장전에서 임의로 섞지 않는다.
- 12×70 슬러그는 산탄 펠릿 대신 단일 발사체를 사용한다.
- 적 방어도는 밴딧 15%, 밴딧 가드 28%, 밴딧 보스 42%로 설정했다.
- 관통력 0은 방어도 효과를 그대로 받고, 관통력 1은 방어도를 완전히 무시한다.
- 기존 저장은 탄창 수만 유지하고 탄종 프로필은 기본탄으로 복원되므로 저장 포맷을 깨지 않는다.

### 재질별 음향

- 발소리: 잔디, 진흙/흙, 콘크리트, 나무, 금속 각 4종.
- 탄착음: 살점, 흙, 콘크리트, 나무, 금속 각 3종.
- 제공된 resource/Sound 원본을 선별해 GameAudioLibrary에 연결했다.
- 플레이어 프리팹에 PlayerFootstepAudio를 영구 부착했다.
- 허브 기본 지면은 콘크리트, 숲 기본 지면은 잔디로 판정하고 콜라이더 이름·레이어·PhysicsMaterial·SurfaceAudioTag로 세부 재질을 덮어쓸 수 있다.

## 직접 확인할 항목

1. 타이틀에서 설정과 종료가 각각 올바르게 열리고 동작하는지.
2. 전체/음악/효과음 슬라이더 체감 범위와 기본 음량이 적절한지.
3. 전체 화면과 네 해상도를 바꾼 뒤 재실행해 값이 유지되는지.
4. HP탄은 비장갑 적에게 강하고, BP/SNB탄은 밴딧 가드·보스에게 상대적으로 유리한지.
5. 12×70 슬러그가 한 발로 나가고 AP 벅샷은 여러 펠릿으로 나가는지.
6. 허브·숲에서 걷기/달리기 발소리 간격과 지면 소리가 자연스러운지.
7. 나무·금속·콘크리트 장애물에 사격했을 때 탄착음 구분이 자연스러운지.
8. 현재 계속하기 저장은 플레이 모드 검증 중 자동 저장된 상태일 수 있으므로 새 게임을 원하면 타이틀의 새 게임으로 초기화할 것.
