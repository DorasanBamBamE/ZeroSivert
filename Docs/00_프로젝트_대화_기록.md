# ZeroSivert 프로젝트 대화 기록

작성: 2026-08-22  
형식: 프로젝트 대화의 핵심 지시·결정·결과 요약

---

## 1. 프로젝트 목표

- Unity 6 기반 2D 탑다운 생존·루팅 게임 제작
- Zero Sievert 원작의 허브·숲 맵·전투·루팅·상점·퀘스트 흐름 재현
- 원작 리소스를 기반으로 타일 이음새, 구조물 충돌, NPC 상호작용을 보정
- 모든 작업은 MD 작업 기록과 검증 결과를 함께 남김

---

## 2. 주요 사용자 지시

- 기존 Unity 프로젝트 구조와 작업 문서를 먼저 전체 파악
- 숲 맵 원작 재현 작업의 누락 부분 점검
- 나무·풀·덤불 밀도를 원작 수준으로 상향
- 빌리지 외곽 중복 구조물과 잘린 도로 수정
- 구조물·울타리 관통 이동 및 벽 너머 사격 방지
- 구조물 안에 적과 상자가 생성되지 않게 스폰포인트 재작성
- 좀비·늑대를 3~5마리 무리로 구성해 4~5개 그룹 배치
- 허브 배경에서 불필요한 NPC 스프라이트 제거
- 바텐더·의사·네트워커·역무원 네 명만 실제 NPC로 유지
- 역무원 대화를 통해 Forest에 출발하는 원작 방식 적용
- 인벤토리와 퀵슬롯 3~6번 연동
- 작업 결과와 향후 계획을 순번 MD 문서로 관리
- Unity 프로젝트와 문서를 GitHub에 백업

---

## 3. 숲 맵 작업 결과

### 지면과 구조물

- 지면 청크의 반투명 알파 구멍 제거
- Nearest 2배 확대와 PPU 32 적용으로 픽셀 이음새 보정
- 빌리지·밴딧 구조물 청크 전면 교체
- 빌리지 외곽을 일반 숲 타일로 변경
- 북쪽 도로와 빌리지 연결로 정렬
- 연결로를 빌리지 프리팹에 포함해 맵 재생성 후에도 유지

### 프롭

- 나무·풀·덤불을 별도 오브젝트로 산포
- 나무 밑동 이동 콜라이더 적용
- Custom Axis 기반 Y 정렬 적용
- 구조물, 진입점, 탈출점 주변 프롭 제외
- Props/Ground/Box 스프라이트 아틀라스 적용

### 충돌과 스폰

- 빌리지 벽과 건물 본체 충돌체 적용
- 밴딧 구조물 7종에 복합 충돌체 적용
- 적·상자 스폰 마커를 구조물 형상에 맞게 재작성
- 구조물 내부 적·상자 생성 방지 런타임 검사 추가
- 적 이동·시야·총알이 Obstacle 콜라이더를 사용하도록 통일

### 야생 적

- 좀비·늑대 가중치 그룹 스폰 테이블 생성
- 맵마다 4~5개 무리 배치
- 무리당 3~5마리 구성
- 구조물·나무·플레이어 안전거리 적용
- 좀비 반경 7, 늑대 반경 9의 그룹 중심 배회 적용

## 4. 상호작용과 UI 작업 결과

- E 입력으로 대화가 열리자마자 닫히는 동일 프레임 입력 문제 수정
- 겹친 시체와 상자는 가장 가까운 하나만 상호작용하도록 초점 중재
- 상점 우측 패널의 GROUND 제목을 NPC 이름으로 수정
- 바텐더와 의사 상점 이름 정상 표시
- 인벤토리 Hover + 3~6으로 소비 아이템 퀵슬롯 등록
- 필드에서 3~6으로 등록된 소비 아이템 사용
- UI가 열린 동안 필드 퀵슬롯 입력 차단

---

## 5. 허브 작업 결과

- NPC가 제거된 최신 허브 배경으로 교체
- 알파 보정·Nearest 2배 확대·PPU 32 적용
- 실제 NPC를 네 명으로 제한

```yaml
NPC_Bartender     : 바텐더
NPC_Doctor        : 의사
NPC_Networker     : 네트워커
NPC_ZoneDeparture : 역무원
```

- 역무원 TrainWorker 2프레임 대기 애니메이션 적용
- 역무원 대화의 출발 버튼으로 Forest 진입
- 직접 진입 트리거 제거
